Pedidos recibidos

Conexión API HTTP para N8N

N8N necesita una clave API para leer el menú y modificar el stock de forma segura.

Tu API Key: Verificando…

Por seguridad, esta llave ya no se genera ni se guarda desde la página (para que nadie pueda verla consultando la página) — se configura como variable de entorno N8N_API_KEY directamente en tu hosting (Easypanel → tu app → Environment). Usa ese MISMO valor en el header Authorization de tus flujos de N8N.

1. Consultar todo el menú

Método GET, URL: /api/get-menu.php, Header: Authorization: Bearer [TU_KEY]

Devuelve el menú completo organizado por día (Lunes a Domingo), con nombre, precio, descripción, categoría, tipo de comida (Desayuno/Almuerzo/Cena), disponibilidad a domicilio, imagen, disponibilidad, stock y el costo extra de "para llevar" ya calculado por platillo.

Parámetros opcionales (van en la URL):

?mealTime=Almuerzo — solo trae esa comida (Desayuno/Almuerzo/Cena). También acepta ?mealTime=now para que detecte automáticamente la comida vigente según la hora del servidor.

?day=Lunes — solo trae ese día. También acepta ?day=today para el día actual.

Ejemplo para traer "solo lo que se puede comprar ahora mismo": /api/get-menu.php?day=today&mealTime=now

Zona de domicilio: la respuesta también incluye deliveryZoneConfig con la dirección de tu local y el rango de carreras/calles a las que sí haces domicilio (si lo configuraste en "Franjas Horarias"). Este dato solo llega hasta acá, protegido con tu API Key — nunca se muestra en la página pública. n8n puede comparar la carrera/calle de la dirección que le dé el cliente contra ese rango para decidir si el domicilio aplica.

2. Actualizar stock de un platillo

Método POST, URL: /api/update-stock.php, Header: Authorization: Bearer [TU_KEY], Body: { "id": 1, "stock": 19 }

Cómo usamos tus datos

Responsable del tratamiento: Restaurante La Delicia es el único responsable del tratamiento de tus datos personales recogidos en esta página y en sus canales de atención (WhatsApp, Telegram, chat web). Ninguna otra empresa ni proveedor externo es responsable de tus datos ni decide qué se hace con ellos.

¿Qué datos pedimos? Cuando haces un pedido en esta página: tu nombre, dirección de entrega, teléfono y, si la dejas, una nota. Si nos escribes por el chat de esta página, WhatsApp o Telegram, guardamos esa conversación para poder atenderte.

¿Para qué los usamos? Únicamente para preparar y entregar tu pedido, contactarte si hay algún problema con él, y responder tus preguntas. No vendemos ni compartimos tus datos con nadie fuera del restaurante.

¿Quién los ve? Solo el personal autorizado del restaurante.

¿Cuánto tiempo los guardamos? El tiempo necesario para gestionar tu pedido y atenderte; después, puedes pedirnos que los eliminemos.

Tus derechos (Ley 1581 de 2012 — Habeas Data, Colombia): puedes pedirnos en cualquier momento que te digamos qué datos tuyos tenemos, que los corrijamos, o que los eliminemos por completo. Escríbenos por WhatsApp o Telegram (los botones flotantes de esta página) y lo hacemos tan pronto lo pidas.
